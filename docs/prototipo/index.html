ENP — app de questões ENEM

Protótipo para decidir se criamos o projeto. O cálculo de chance é real (TRI 3 parâmetros + nota de corte); questões, cortes e pesos são de exemplo.

O que testar
  1. Escolha curso, universidades e modalidade no início.
  2. Responda questões e veja a chance mudar após cada uma.
  3. Faça o simulado rápido (8 questões).
  4. Em Chances, use “Simular aluno” para ver a estimativa convergir com muitas questões.
  5. Em Planos, troque de plano e veja o que cada degrau libera.
Como a chance é calculada

Nota por área estimada por TRI (EAP) com erro padrão → média ponderada pelos pesos do curso → P = Φ((nota − corte) / √(σ²nota + σ²corte)). Com poucas respostas a incerteza é alta e a chance fica perto do meio; ela fica mais firme conforme o aluno pratica.

Não usa armazenamento: recarregar a página reinicia o protótipo.
